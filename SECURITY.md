# Política de seguridad

## Alcance

Esta política cubre el contenido, código, configuraciones y workflows publicados en este repositorio.

## Reportar una vulnerabilidad

No publiques secretos, datos personales ni detalles de explotación en un issue público. Utiliza **Report a vulnerability** en la pestaña **Security** de GitHub para enviar el informe de forma privada. Si esa opción no está disponible, solicita un canal privado al mantenedor antes de compartir los detalles.

Incluye el commit o versión afectada, componente, pasos mínimos de reproducción, impacto y mitigación sugerida. Redacta cualquier dato sensible y no adjuntes credenciales.
